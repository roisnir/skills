# Claude Skills

Skills are slash commands that live in `~/.claude/skills/` — copy a folder there and it shows up as `/skill-name`.

---

## [idea-incubator](./idea-incubator/)

Walk a half-formed idea through a structured conversation to a concrete one-pager.

> Best used in **[Claude.ai](https://claude.ai) web chat** — the skill produces markdown artifacts and an HTML one-pager that render in the artifact preview pane. Works in the terminal too, but you'll get raw text and HTML instead.

```
/idea-incubator wouldn't it be great if you had a claude plugin that triggers the coffee machine every time it thinks for a long time?
```
